# Sagarvani --- User Flows

## Flow A --- First visit

Home → Understand proposition → See ORCA/agents → See stakeholder value
→ Click Try Sagarvani → Dashboard.

## Flow B --- Text query

Dashboard → enter question → submit → ORCA interprets → agents run →
map/layers update → validation → answer + confidence + evidence.

## Flow C --- Voice query

Dashboard → microphone → listening → transcript → user can confirm/edit
→ submit → normal ORCA pipeline.

## Flow D --- Contradiction

Query → agents produce inconsistent evidence → status becomes Conflict /
Re-checking → ORCA re-plans → evidence reconciled → Validated or
Degraded Confidence → recommendation.

## Flow E --- Evidence inspection

Final answer → Evidence → source list → source summary → reasoning
trace.

## Flow F --- Alert

Alert appears → severity indicated → user selects alert → map focuses
relevant area → context displayed.

## Flow G --- History

Previous query → select session → restore conversation/reasoning/map
state.

## Flow H --- Low-connectivity concept

Marketing site explains that the same intelligence layer is designed for
Web/App, Helpline and low-bandwidth communication. Production
IVR/helpline implementation remains beyond the current web MVP.
