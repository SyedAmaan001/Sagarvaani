# Sagarvani — Image Generation Prompt Pack

## Global visual constraints

Use these constraints for every generated image:

- premium editorial photography
- realistic Indian Ocean / coastal context
- dark navy / deep-blue atmosphere
- cyan-blue highlights only where appropriate
- cinematic but credible
- no fantasy sci-fi
- no floating hologram clichés
- no embedded text
- no logos
- no watermarks
- no UI labels
- no artificial typography inside image
- composition must leave negative space for web copy
- high detail
- natural lighting
- suitable for dark navy website treatment
